## API Usage

### Basic Request

```bash
GET https://avatune.sebasgc.xyz/?theme=nevmstas&hair=short
```

### Example Response

The API returns an SVG image that can be used directly in `<img>` tags or embedded in your HTML:

```html
<img src="https://avatune.sebasgc.xyz/?theme=yanliu&seed=user123" alt="Avatar" />
```

## Parameters

### Required Parameters

| Parameter | Description | Example |
| --------- | ----------- | ------- |
| `theme`   | Theme name from `GET /themes` | `yanliu`, `kyute`, `micah` |

### Optional Parameters

| Parameter         | Description                | Default       |
| ----------------- | -------------------------- | ------------- |
| `size`            | Avatar size in pixels      | Theme default |
| `seed`            | Seed for deterministic generation. Use the same theme and seed to regenerate the same avatar. | Random seed returned in `X-Avatar-Seed` |
| `backgroundColor` | Background color (hex)     | Theme default |
| Theme options     | Part/color options supported by the selected theme, such as `hair`, `eyes`, `body`, `hairColor`, or `skinColor` | Random/theme default |

## Themes

Use `GET /themes` to get the current list of available themes:

```bash
curl https://avatune.sebasgc.xyz/themes
```

Example response:

```json
{
  "themes": ["ashley-seo", "ashleyy", "fatin-verse", "kyute", "micah", "miniavs", "nevmstas", "pacovqzz", "pawel-olek-man", "pawel-olek-woman", "yanliu"]
}
```

## Seeds

Seeds make avatars repeatable. This URL always generates the same avatar because both `theme` and `seed` are fixed:

```bash
GET https://avatune.sebasgc.xyz/?theme=yanliu&seed=user-123
```

If you omit `seed`, the API generates one and returns it in the `X-Avatar-Seed` response header. Save that value with the `X-Avatar-Theme` header if you want to regenerate the avatar later.

## Random Avatars

Use `GET /random` when you want the API to choose random values:

```bash
GET https://avatune.sebasgc.xyz/random
GET https://avatune.sebasgc.xyz/random?theme=kyute
GET https://avatune.sebasgc.xyz/random?theme=kyute&seed=user-123
```

`/random` returns SVG and includes `X-Avatar-Theme` and `X-Avatar-Seed` headers.

## Rate Limiting

The API enforces rate limits per IP address to ensure fair usage:

- **10,000 requests per minute by default**
- Exceeding the limit blocks requests for **10 minutes by default**

Limits can be configured by deployment environment variables.

### Rate Limit Response

When rate limits are exceeded, the API returns:

- **Status Code**: `429 Too Many Requests`
- **Header**: `Retry-After` with seconds until retry
- **Response Body**: `Rate limit exceeded. Try again later.`

## Caching

All successful responses include cache headers for optimal performance:

```
Cache-Control: public, max-age=31536000, immutable
```

This means:

- Responses are cached for 1 year
- Content is immutable (won't change)
- Can be cached by browsers and CDNs

<Aside type="tip">
  Use the `seed` parameter to generate consistent avatars for the same user
  across requests.
</Aside>

## CORS

The API supports Cross-Origin Resource Sharing (CORS), allowing requests from any origin:

```
Access-Control-Allow-Origin: *
```

## Error Responses

### Invalid Theme

```text
Unknown theme: unknown. Available: ashley-seo, ashleyy, fatin-verse, kyute, micah, miniavs, nevmstas, pacovqzz, pawel-olek-man, pawel-olek-woman, yanliu
```

**Status Code**: `400 Bad Request`

### Rate Limit Exceeded

```text
Rate limit exceeded. Try again later.
```

**Status Code**: `429 Too Many Requests`

```typescript
import { createClient } from "@avatune/api-client";

const client = createClient();
```

### Error Handling

```typescript
import { createClient, AvatuneApiError } from "@avatune/api-client";

const client = createClient();

try {
  const svg = await client.getAvatar({ theme: "yanliu", seed: "test" });
} catch (error) {
  if (error instanceof AvatuneApiError) {
    if (error.isRateLimited) {
      console.log(`Rate limited. Retry after ${error.retryAfter} seconds`);
    } else {
      console.log(`API error: ${error.data.error}`);
    }
  }
}
```

## Infrastructure

The Avatune API is built with:

- **Cloudflare Workers** - Edge computing for low latency
- **Cloudflare KV** - Distributed key-value storage for rate limiting
- **Global CDN** - Deployed to 300+ locations worldwide


For deployment instructions, see the [GitHub repository](https://github.com/avatune/avatune/tree/main/apps/cloudflare-worker).

## Best Practices

1. **Use Seeds for Consistency**: Always use the same `seed` parameter for a specific user to ensure their avatar remains consistent
2. **Cache Responses**: Take advantage of the long cache headers to minimize API calls
3. **Respect Rate Limits**: Implement proper error handling for 429 responses
4. **URL Encode Parameters**: Always URL encode color values and other special characters

### Example with URL Encoding

```javascript
const params = new URLSearchParams({
  theme: "yanliu",
  seed: "user-123",
  hairColor: "#FF5733", // Will be properly encoded
  backgroundColor: "#3498DB",
});

const url = `https://avatune.sebasgc.xyz/?${params}`;
```
